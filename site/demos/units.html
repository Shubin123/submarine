Physical → lattice units

An LBM run is only as credible as its unit mapping. Enter the physical case and the lattice resolution; the converter reports Reynolds number, relaxation time τ, lattice Mach number and time step, and flags combinations that are unstable or compressibility-polluted.

Result

τ as resolution grows

At vehicle Reynolds numbers (10⁶–10⁷) a resolved BGK lattice would need billions of nodes; practical LBM for such cases relies on wall models and LES/MRT/cumulant collision operators. That cost is part of the fair comparison.

Use as a library

import { toLattice, FLUIDS } from './lib/units.js';
const r = toLattice({ length: 1.6, speed: 1.5, nu: FLUIDS.seawater15.nu, cells: 400, uLattice: 0.05 });
// → { re, dx, dt, nuLattice, tau, mach, warnings, cellsForTau(target) }
