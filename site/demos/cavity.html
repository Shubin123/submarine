How to read this

Same physics, different unknowns. The FVM solves for face velocities and cell pressures; the LBM evolves 9 distributions per node and recovers velocity as a moment. Node counts are not equivalent degrees of freedom.

Compare at matched error. Watch the max-deviation number, not the pretty colours. Only once both are below the same tolerance does a wall-clock comparison mean anything.

Library use. import { CavityFVM } from './lib/fvm.js' and import { lidDrivenCavity } from './lib/lbm.js' — both are dependency-free ES modules that also run under Node for regression tests.
