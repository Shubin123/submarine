Finite volume vs lattice Boltzmann, running in your browser

A practical choice framework for submarine and vehicle-flow simulation, with working browser demos of each part: both solvers on a verification benchmark, a lattice-unit converter, and a reduced-order vehicle model that exports to Gazebo.

Run the benchmarkExplore drone-bay taskOpen ArmLab ↗Read the note

Bottom line

Start with a finite-volume baseline (OpenFOAM) for the hull. Evaluate LBM (OpenLB / Palabos) on the same low-Mach, single-phase case only after both meet the same error and refinement criteria. Use Gazebo for robot dynamics and control, fed by a reduced-order hydrodynamic model — not as the CFD solver.

The web libraries

Each demo is a thin page over a dependency-free ES module in lib/. They import directly from this site or from the repository, and the same files run under Node for regression tests (npm test).

ModuleProvidesVerified by
lib/lbm.jsD2Q9 BGK solver, Guo forcing, moving-wall bounce-back, velocity inlet / pressure outlet, momentum-exchange forces; cavity and cylinder presetsPoiseuille profile, mass conservation, Ghia cavity
lib/fvm.jsStaggered-grid finite-volume Navier–Stokes, projection with conjugate-gradient pressure solveGhia cavity, grid-refinement trend, discrete divergence
lib/units.jsPhysical ↔ lattice conversion, fluid property presets, stability warningsSelf-consistency checks
lib/hydro.jsITTC-1957 friction, Hoerner form factor, Lamb added mass, 4-DOF manoeuvring model, drag tables, Gazebo SDF exportSphere limit, steady-speed balance, sign conventions

Existing web tools worth reusing

The survey behind the demos found mature browser-side projects for viewing and integration; building our own was only needed for the small verified solvers.

vtk.js (Kitware)

Scientific visualisation on the web (WebGL, WebGPU coming). A natural viewer for exported OpenFOAM/OpenLB fields; rom.js / cfd.xyz uses it to publish OpenFOAM results.

GitHub · cfd.xyz paper

gzweb

Browser client for Gazebo built on three.js; the newer gazebo-web/gzweb is published as an npm library for current Gazebo.

gazebo-web/gzweb · osrf/gzweb (Classic)

GPU LBM in the browser

WebGL2 and WebGPU D2Q9 implementations show the same algorithm scaled onto the GPU — the upgrade path if these demos need larger lattices.
