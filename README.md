# Finite Volume vs. Lattice Boltzmann

A concise, source-linked research note and reproducible benchmark plan for choosing between finite-volume (FVM) and lattice-Boltzmann (LBM) CFD for an underwater vehicle or other flow-coupled robotics project.

Read the published note at the project's GitHub Pages site after deployment, or start with [research.md](research.md).

## Scope

This repository is a research brief and experiment specification. It does **not** claim to contain measured solver results: the FVM/LBM toolchains and a defined geometry have not been run in this repository.

## Publishing

GitHub Actions deploys the static page in `site/` to GitHub Pages whenever `main` changes.
